# Staywell House

A responsive hotel reservation website built with plain HTML, CSS, and JavaScript.

## Features
- Room browsing with room-type filters and guest-capacity filtering
- Check-in/check-out dates, guest count, and estimated stay prices
- Reservation form for contact details, arrival time, and special requests
- Confirmation codes and a reservation list saved in the browser
- Responsive layout and keyboard-dismissible dialogs

## Run locally
Open `index.html` in a browser, or run a local static server:

```bash
npx serve .
```

## Deploy on Vercel
Import this folder or its Git repository into Vercel. It is a static site and does not need a build command.

> This is a front-end demo. Reservations are stored only in the visitor's browser; it does not process payments or reserve shared room inventory.
